# Download Archive

`The_Cradle_of_Life_Press_Kit.zip` is the public archive linked throughout the website.

Rebuild it from the current project assets with:

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-press-kit.ps1
```

The archive contains fact-sheet text, the approved developer biography, pronunciation guidance, creator policies, current web artwork, screenshots, and any optional media enabled in `press-kit-config.json`.
