# Gameplay Captures

This folder contains four approved gameplay captures. Tactical combat and exploration include optimized GIFs, MP4 downloads, and stills. Character creation and Shimmer combat include smooth MP4 downloads and stills.

Recommended filenames:

- `CradleOfLife_Gameplay_TacticalCombat.gif`
- `CradleOfLife_Gameplay_TacticalCombat.mp4`
- `CradleOfLife_Gameplay_TacticalCombat-still.jpg`
- `CradleOfLife_Gameplay_Exploration.gif`
- `CradleOfLife_Gameplay_Exploration.mp4`
- `CradleOfLife_Gameplay_Exploration-still.jpg`
- `CradleOfLife_Gameplay_CharacterCreation.mp4`
- `CradleOfLife_Gameplay_CharacterCreation-still.jpg`
- `CradleOfLife_Gameplay_ShimmerCombat.mp4`
- `CradleOfLife_Gameplay_ShimmerCombat-still.jpg`

The matching paths are configured in `press-kit-config.json`. MP4 previews are used for the site to avoid the stutter and oversized payload of high-weight GIF playback.
